# Codex Project History v0.1.5

This maintenance release makes slow-database behavior honest and keeps distribution scoped to
GitHub Releases.

## Changes

- A timeout reading the newest Codex state database is now terminal. The picker reports a concise
  error instead of falling back to an older database and showing stale history.
- The package is marked private so npm refuses publication. VSIX packaging and GitHub Releases
  remain the supported distribution path.

## Requirements and limits

- macOS
- VS Code 1.95 or newer
- The official OpenAI Codex extension (`openai.chatgpt`)
- `/usr/bin/sqlite3`

OpenAI does not document the local database schema or editor route as public extension APIs.
Linux and Windows remain unvalidated. This change does not alter the read-only database boundary.
