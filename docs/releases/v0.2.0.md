# Codex Project History v0.2.0

This release adds a project-aware archived-chat picker and a read-only transcript viewer. Viewing
an archive does not restore it. The separate **Restore Archived Chat** command requires a modal
confirmation and invokes `codex unarchive <UUID>` without a shell or direct database writes.

## Requirements and limits

- macOS, VS Code 1.95 or newer, the official OpenAI Codex extension, and `/usr/bin/sqlite3`.
- Archived JSONL and the Codex database/editor route are private compatibility surfaces. The
  viewer confines resolved transcript paths to configured archive roots, filters known injected
  context and tool/image content, and caps rendered text. A future Codex update may need a fix.
- Linux, Windows, and VS Code Marketplace distribution are not validated or claimed.
