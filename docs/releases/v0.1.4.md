# Codex Project History v0.1.4

The first public release adds a current-project-first picker for local VS Code Codex chats.

## Highlights

- Search local Codex chats by title, repository, branch, and working directory.
- Put chats from the current VS Code project first.
- Open the picker from **Codex: Search Chats by Project**, **Project Chats** in the status bar, or
  **Control+Command+H** on macOS.
- Keep Codex history local and read-only.
- Recover from the reproduced missing-WAL-sidecar SQLite failure with a bounded, immutable
  read-only retry.

## Requirements and limits

- macOS
- VS Code 1.95 or newer
- The official OpenAI Codex extension (`openai.chatgpt`)
- `/usr/bin/sqlite3`

OpenAI does not document the local database schema or editor route as public extension APIs, so a
future Codex release may require a compatibility update. This release has not been validated on
Linux or Windows. The synthetic activation test validates the picker, not reopening a real chat.
