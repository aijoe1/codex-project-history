# Codex Project History v0.3.0 — release preparation

This is a pre-release validation record. It is **not** a public release receipt. Product changes
merged through [PR #6](https://github.com/aijoe1/codex-project-history/pull/6) as `main` commit
`cd3b2f354600fd98a3fd45a436114f0f3bf622ba`; post-merge macOS and Ubuntu CI passed in
[run 39550591999](https://github.com/aijoe1/codex-project-history/actions/runs/39550591999).

## Changes

- Active and archived chat pickers start with the current VS Code project when a workspace is open.
- **Show all projects** and **Show current project only** switch scope without discarding typed search.
- Current-project search applies before the recent-chat limit, so older chats from the current
  repository or its worktrees are not crowded out by activity elsewhere.
- Opening a chat from another project in the current VS Code window requires confirmation.

## Limits and landing gate

- The synthetic fixture proves picker behavior; real-chat reopening was separately observed by
  the owner as above. Normal VS Code and the dotfiles installation remain on v0.2.0.
- The Codex database schema and editor route are private compatibility surfaces. A future Codex
  update may require maintenance. Linux, Windows, and Marketplace distribution are unvalidated.
- The product branch is merged. A documentation-only PR, its passing CI, and separate approval
  to merge that PR remain before tagging `v0.3.0` and publishing its GitHub VSIX. After
  publication, independently download the public VSIX and compare its SHA-256 with the candidate
  above; the release is not verified until that check passes.
  GitHub release approval does not install v0.3.0, sync dotfiles, or publish to Marketplace.
